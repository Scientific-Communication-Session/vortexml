# Earlier tutorial recordings

Clips that used to be on the site, kept for the record. They are not part of
the build and nothing links to them.

| Folder | What it is |
|---|---|
| `2026-11-original-ui/` | The 14 clips (`.mp4`, each with a `.png` of its first frame) recorded in November 2026 against the interface before the "Violet Night" redesign, in a 1280 × 800 window. Replaced on 26 November 2026 by recordings of the redesigned interface in a 1600 × 1000 window, which show the whole page. |

Before re-recording (`node record.mjs`), copy the clips about to be replaced
from `frontend/public/tutorial/` into a new folder here.
